# Exercícios — Semana 35 — Contribuição e Comunidade

## Exercício 1 — Mapeando Contribuições no jPOS

Acesse o repositório público do jPOS (https://github.com/jpos/jPOS) e responda:

1. Quantas issues abertas existem com a label "bug"? Liste os títulos das 3 mais antigas.
2. Existe alguma issue marcada como "good first issue" ou "help wanted"?
   Se sim, descreva uma que você poderia abordar com o conhecimento do curso.
3. Qual foi o último commit no repositório? O que ele mudou?
4. O jPOS usa qual sistema de build e qual versão mínima de Java no `pom.xml` principal?

Se não tiver acesso ao GitHub no momento, responda com base no que a teoria descreve
sobre como identificar oportunidades de contribuição adequadas para iniciantes.

**Objetivo:** familiarizar-se com o processo de descoberta de oportunidades em open source.

## Exercício 3 — Participação Efetiva em Comunidades

Reescreva cada mensagem abaixo para torná-la uma contribuição de qualidade
à comunidade técnica de pagamentos:

**Mensagem 1 (pergunta ruim):**
> "Alguém sabe como configurar o jPOS? Não está funcionando."

**Mensagem 2 (opinião não construtiva):**
> "Nossa empresa tentou usar Stripe mas é muito limitado para o mercado brasileiro.
>  jPOS é muito melhor."

**Mensagem 3 (pedido de ajuda genérico):**
> "Preciso implementar chargeback. Como faz?"

Para cada reescrita, inclua: contexto do que já foi tentado, o problema específico,
código ou log relevante (pode ser fictício) e uma pergunta precisa.

**Objetivo:** praticar a comunicação técnica construtiva que agrega valor às comunidades.

## Exercício 5 — Análise: GitHub como Portfólio

Avalie dois perfis hipotéticos de GitHub de candidatos a uma vaga de Staff Engineer
em pagamentos e determine qual contrataria e por quê:

**Candidato A:**
- 847 commits no ano, majoritariamente em repositórios privados
- 1 repositório público: `payment-switch-lab` com README de 3 linhas ("jPOS switch")
- 0 contribuições em projetos externos
- 0 issues abertas ou respondidas

**Candidato B:**
- 124 commits no ano, todos em repositórios públicos
- 1 repositório público: `iso8583-switch` com README de 400 palavras explicando
  o projeto, diagrama de arquitetura, guia de setup e seção "Decisões de Design"
- 3 PRs aceitos no jPOS (2 de documentação, 1 correção de bug menor)
- 8 issues respondidas no repositório do jPOS com respostas detalhadas

1. Qual candidato você contrataria para uma posição de Staff Engineer? Justifique.
2. O Candidato A tem 6x mais commits. Isso conta a favor? Por quê (não)?
3. O que o Candidato A poderia fazer em 30 dias para tornar seu perfil competitivo?
4. Que tipo de empresa preferiria o Candidato A? E o Candidato B?

**Objetivo:** compreender o que torna um portfólio técnico público efetivamente convincente.
